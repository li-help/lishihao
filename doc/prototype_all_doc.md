# prototype_all_doc.md 原型总文档（包含两张原型图：首页 + 个人中心）

## 基础通用规范（两页面共用，统一标准）

1. 基准设计尺寸：375×812（iPhone X）
2. 还原标准：页面视觉误差≤10%，满足考核90%还原要求
3. 全局UI统一规范
   - 主色调：#2563EB
   - 文字色：一级标题#222222 / 正文#333333 / 辅助#666666 / 浅灰提示#999999
   - 分割线：#EEEEEE，页面背景底色#F5F7FA
   - 圆角：小8px、中12px、头像50%圆形
   - 间距基数：4px / 8px / 12px / 16px
   - 通用交互：所有可点击组件加水波纹；图片加载失败展示默认占位图；接口异常弹出Toast；页面初始化展示Loading占位

## 第一张原型：首页 HomePage

### 页面模块从上至下

1. **顶部导航AppBar**
   - 高度48px，背景#2563EB；左右内边距16px
   - 左侧：24×24 Logo图标 + 白色16号Medium字体「首页展示」
   - 右侧：22×22搜索、消息图标
   - 交互：点击图标跳转对应页面

2. **Banner轮播模块**
   - 外边距上下12px、左右16px；容器高度180px，圆角12px
   - 图片填充BoxFit.cover；3s自动轮播，支持左右滑动
   - 底部圆点指示器：激活#2563EB，未激活#CCCCCC
   - 点击Banner跳转对应链接；数据接口：GET /api/home/banner

3. **功能分类网格**
   - 外边距上下12px、左右16px，4列均分布局
   - 单Item高90px：48×48圆形图标 + 下方12号灰色文字
   - 网格横向间距8px，纵向12px；点击跳转对应功能；接口：GET /api/home/category

4. **推荐资讯列表**
   - 标题栏：「推荐资讯」加粗15号#222，右侧「更多」蓝色13号可点击
   - 列表卡片高110px、圆角10px、轻微阴影，左图右文布局
     - 左侧封面100×80px圆角8px；右侧文字区域：标题两行截断、简介一行截断、底部小号时间
   - 支持下拉刷新、上拉分页加载；无数据展示EmptyWidget；接口：GET /api/home/list?pageNum=1&pageSize=10

5. **底部Tab导航（公共组件，与个人中心复用）**
   - 高度60px，顶部#EEEEEE分割线，纯白背景
   - 三个Tab：首页、分类、我的；选中状态图标文字#2563EB，未选中#999999
   - 图标24px，标签文字11px；切换Tab平滑切换页面

### 首页验收标准

1. 五大模块完整、顺序与文档一致；
2. 尺寸、色值、间距误差＜10%；
3. 轮播、网格、列表、下拉/上拉交互完整；
4. 加载、空数据、异常状态UI齐全；
5. 所有数据从后端接口动态渲染，禁止静态写死。

## 第二张原型：个人中心 MePage

### 页面模块从上至下

1. **用户信息头部渐变卡片**
   - 高度160px，渐变#2563EB→#60a5fa，内边距上下30px、左右16px
   - 左侧72×72圆形头像（3px白色边框）；右侧：18号粗体白色昵称、12号浅灰用户ID、白色边框圆角编辑按钮
   - 交互：点击头像换头像、点击编辑跳转资料页

2. **数据统计栏**
   - 外边距上下12px左右16px，白色圆角12px，高度80px三等分布局
   - 每项：大号粗体数字 + 下方小号说明文字；竖线#EEEEEE分隔三栏（积分/收藏/浏览）
   - 点击任意统计项跳转详情页面

3. **功能菜单列表**
   - 外边距左右16px，单条Item高56px，白底
   - 布局：左侧24px主色图标 + 中间14号文字 + 右侧灰色箭头；底部分割线缩进16px
   - 菜单固定顺序：我的订单→我的优惠券→消息通知→系统设置→关于我们
   - 点击菜单跳转对应页面

4. **底部Tab导航（复用公共组件）**
   - 当前页面「我的」Tab激活，切换Tab返回首页/分类页

### 个人中心配套接口

```
GET /api/user/info
返回结构：
{
  "avatar": "图片url",
  "nickName": "用户昵称",
  "userId": "Uxxxx",
  "points": 积分数字,
  "collectCount": 收藏数,
  "viewCount": 浏览记录数
}
```

### 个人中心验收标准

1. 四大模块完整，布局顺序匹配文档；
2. UI尺寸、色彩、间距符合通用规范，还原度≥90%；
3. Tab可与首页互相切换，页面状态保留；
4. 用户数据通过后端接口动态渲染；
5. 加载失败、空数据、网络异常状态完整处理。
